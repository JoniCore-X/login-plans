# Política de Seguridad

## Reportar una vulnerabilidad

Si encuentras un problema de seguridad, **no abras un issue público**.
Escríbelo directamente a:

**jonicorex40@gmail.com**

Incluye: descripción, pasos para reproducir y posible impacto.
Responderemos lo antes posible con un plan de corrección.

Para bugs no relacionados con seguridad, usa
[Issues](https://github.com/JoniCore-X/login-plans/issues) o
[Discussions](https://github.com/JoniCore-X/login-plans/discussions).
